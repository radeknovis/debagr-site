Privacy, terms, and support

Technical-preview terms updated 4 November 2026. Publisher: Radek Novak. Processor terms, refund policy, governing law, and counsel review must be completed before any sale.

Privacy

Debagr works on the paired build server and currently has no analytics, advertising, crash SDK, customer account, or Debagr cloud. It processes visible device names, identifiers, app paths and bundle identifiers, deployment results, macOS version, developer-tools availability, and optional Tailscale status.

Private connection profiles and the last deployment receipt persist under ~/.config/debagr/. Profiles include device identifiers, VPN endpoints, and captured local service metadata. Data stays on the build server unless the user copies and sends a diagnostics report. Reports can include device names and hostnames. Review them before sharing.

Optional sponsorship

Funding channels are in preparation. When activated, GitHub Sponsors or Ko-fi process optional support under their own policies. Sponsorship supports development; it does not buy a software license, guaranteed support, or a delivery date. There is no active product checkout or announced subscription price.

Licence summary

A future paid subscription will license one named user to run Debagr on Macs and Target Devices they own or control. Users may not access systems without authorization, bypass Apple trust controls, resell access, or use Debagr in safety-critical contexts.

Debagr executes deployment on the Mac paired by Apple; it does not transfer pairing state or make devices appear on callers’ machines. Platform and signing changes can interrupt deployment. Final consumer rights, liability, termination, refund, and governing-law terms will be shown before purchase.

Support

  1. Confirm Xcode and devicectl are installed on the build server.
  2. Pair over USB, trust that Mac, and enable Developer Mode.
  3. Keep the device unlocked for the first install.
  4. Confirm the signed device .app exists on the build server.
  5. Test the Debagr command locally before invoking it through SSH.
  6. Choose Copy Diagnostics, review the result, and share it only through private reporting, below.

Contact

Report problems in GitHub Issues with the exact macOS, Xcode, and iOS versions. Never post device identifiers, hostnames, VPN addresses, pairing material, or diagnostics in a public issue.

Send security vulnerabilities, privacy requests, and requested diagnostics through GitHub private vulnerability reporting. Support is best effort during the technical preview.

Uninstall

Turn off Launch at Login, quit Debagr, move the app to Trash, then optionally run defaults delete com.debagr.app. To discard saved connection data as well, back up any profiles you want to retain, then remove only ~/.config/debagr/. This does not revoke Apple pairing or uninstall deployed apps.
